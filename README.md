# Лабораторна робота № 3 — Основи роботи з Git
## Опис проєкту
Навчальний репозиторій для відпрацювання базових та командних можливостей системи контролю версій Git і платформи GitHub.
**Виконав:** Прізвище Ім'я, група ХХ-ХХ
## Основні етапи роботи
- Ініціалізація та клонування репозиторію
- Робота з гілками та Pull Request
- Вирішення конфліктів злиття (Merge Conflict)
- Налаштування `.gitignore`, `LICENSE`, Release та GitHub Actions
## Таблиця використаних команд
| Команда | Призначення |
| :--- | :--- |
| `git clone` | Клонування віддаленого репозиторію |
| `git commit` | Фіксація змін у локальній історії |
| `git push` | Надсилання комітів на GitHub |
| `git revert` | Безпечне скасування змін новим комітом |
